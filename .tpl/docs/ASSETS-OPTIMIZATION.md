# 图片体积优化（1.0.1）

运行素材包含188,692,173字节JPG/PNG原图，个别图片达8322×6657，原生img直接请求原图。现转换为WebP（quality=90、effort=6、alphaQuality=100），不裁切、不放大，保留透明通道。原图仍可在Git历史追溯，来源URL、sourceSha256和新文件sha256记录在public/templates/zentra/sources.json。

依据1360px最大内容宽度与实际栅格，完整宽度图片上限2720px，作品及画廊1600px，团队头像640px，评价头像160px，覆盖各区域约2倍显示像素。97个原图转为97个WebP文件；相同字节的历史命名别名保留，以维持画廊排除主图时的既有比较语义。图片合计31,112,498字节，减少约83.6%。源码与动态图片文件名一并更新，运行包不保留原图副本。

不增加或升级依赖；优化使用既有Next工具链中的Sharp。字体继续按原CSS分片加载，没有按字符串检索结果误删字体。完整转换清单、尺寸、字节数与摘要见reports/asset-optimization.json。视觉复核不代表全部动效逐帧验收。
